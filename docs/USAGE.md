# PopupGuard · 独立弹窗拦截

**截图选窗添加规则，错过的弹窗从历史里补拦截。**

**[下载 Windows 版](https://github.com/batai1222/PopupGuard/releases/latest)** · [使用方法](#使用方法) · [反馈问题](https://github.com/batai1222/PopupGuard/issues)

PopupGuard 把弹窗拦截做成一个独立的小工具：截图点选目标、记录短暂出现的窗口、逐条管理规则，关闭主页面后继续在托盘运行。鼠标左键点一下托盘图标即可回到主页面。

当前版本 **1.0.4**，主程序约 **66 KiB**。源码公开，记录保存在本机。适用于 Windows 10/11 x64 交互式桌面，需要 .NET Framework 4.x；使用 C# 和 WinForms 实现。

## 下载和运行

点击[直接下载 PopupGuard.exe](https://github.com/batai1222/PopupGuard/releases/latest/download/PopupGuard.exe)，保存到可写的文件夹，双击运行即可，无需安装或解压。也可从 [Releases](https://github.com/batai1222/PopupGuard/releases) 下载 ZIP 压缩包。程序不带预设拦截规则，需要先添加目标窗口。

## 使用方法

- **截图拦截**：在屏幕上选中要拦截的窗口，再点击“拦截”。按 Esc 或右键可取消。
- **历史弹窗**：查看记录过的窗口，选中后添加拦截规则。一闪而过的窗口可能只有名称和时间，没有截图。
- **主页面**：显示规则、成功拦截次数和最近时间。取消勾选暂停该条规则；每行右侧“删除”会立即移除规则，历史记录仍保留。
- **托盘**：左键单击图标打开主页面，右键打开菜单。关闭主页面后继续在托盘运行；菜单中的“退出”停止程序。

历史记录保存在程序旁的 `data` 文件夹，包含窗口标题、程序路径和缩略图，最多保留最近 300 种窗口。程序没有上传记录的功能。不要把自己的 `data` 文件夹提交到仓库。

规则按程序完整路径、窗口标题、窗口类、类型和尺寸识别；软件升级或弹窗变化后可能需要重新选择。完整精确规则会尽早检查窗口，命中后不再等待截图保存。对于已显示的目标，先请求隐藏，再请求关闭。关闭失败时会请求恢复窗口，并显示失败状态，不增加成功计数。

## 编译

使用 Windows 自带的 .NET Framework 编译器，无需第三方依赖。在仓库目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

输出为 `build\PopupGuard.exe`。上述执行策略参数只作用于这次编译进程。

## 后台启动与权限

`PopupGuard.exe --autostart` 可隐藏主页面启动；再次启动同一目录的程序会打开现有实例。

程序默认使用当前权限运行，不自动安装自启任务。若需要处理管理员权限窗口，可手动“以管理员身份运行”；需要登录自启时，可在 Windows 任务计划程序中设置当前用户登录触发，参数为 `--autostart`，按需要勾选“使用最高权限运行”。

## 已知限制

- 独立窗口事件监听是异步的，不能保证从创建前阻止窗口，也不能保证所有弹窗完全不闪一下。
- 隐藏、关闭与恢复请求需要目标软件处理；拒绝关闭或卡住的窗口可能无法及时处理。
- 最新界面及提前拦截修改经过编译与静态审查，未进行桌面操作测试；这不是对所有软件的拦截效果保证。
- 这是独立编写的工具，交互方式参考常见弹窗拦截工具，不是火绒或卡巴斯基官方软件。

## 仓库内容

`src` 保存源代码和程序 manifest，`build.ps1` 用于编译，`release` 保存当前可运行程序及其 SHA-256。仓库不包含个人规则、历史、窗口截图或本机安装配置。
